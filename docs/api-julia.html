Write Rumi files from Julia arrays, or read selected windows, bands and time steps. The reader pairs each file with its external header.

Install

using Pkg
Pkg.Registry.add(url = "https://github.com/asterisk-labs/AsteriskRegistry")
Pkg.add("Rumi")

The package calls librumi directly, and compresses frames with the GeoZL inside it. It loads the library named by RUMI_LIB, then the one make build writes to core/build in a checkout, then the artifact a release publishes for Linux x86-64 and macOS arm64, downloaded on first use and kept in the Julia depot. Loading fails with a librumi built for another C API version.

using Rumi

file = Rumi.open("scene.rumi", Base.read("scene.header"))
chip = Rumi.read(file; bands = [4, 8], time = 1:3, window = (1, 1, 256, 256))
size(chip)                                   # (256, 256, 2, 3)
meta = info(file)
close(file)

Functions

Call Rumi.open, Rumi.read, Rumi.frames and Rumi.write with the module prefix. Invalid requests throw ArgumentError; other library failures throw RumiError.

open

Rumi.open(source, header) -> Dataset

Pairs a local path or remote URI with its external header. Opening checks that the header matches the source and reads the transform, CRS, band descriptions and time axis. A leading ~ in the path is expanded.

sourceA local path or remote URI.
headerThe external header bytes, any AbstractVector{UInt8}. The Dataset keeps its own copy.

Returns a Dataset. A header that cannot be parsed throws RumiError, and one that does not match the source throws ArgumentError.

read

Rumi.read(file::Dataset; time=nothing, bands=nothing, window=nothing,
    pattern=nothing) -> Array
Rumi.read(source, header; kwargs...) -> Array

Reads a selection into a new array of the file's element type. The second form opens the source, reads it and closes it.

timeOne-based time steps, an integer or a collection of integers, kept in the order given. nothing reads every step.
bandsOne-based bands, in the same form.
window(row, column, height, width) with a one-based origin. It must lie inside the image, and nothing reads the whole image.
patternThe output axes, as in Arrays. nothing uses "t b y x" when the file has more than one time step, otherwise "b y x".

An empty selection, an index outside the file, a window past the image or a closed Dataset throws ArgumentError.

chip = Rumi.read(file; time = [2, 1], bands = [3, 1], window = (2, 3, 3, 4))
size(chip)                                   # (4, 3, 2, 2)

read_many

read_many(files::AbstractVector{<:Dataset}; windows=nothing, time=nothing,
    bands=nothing, pattern=nothing) -> Array
read_many(sources, headers; kwargs...) -> Array

Reads one window from each Dataset into one array, as a training batch needs. Every file takes the same time steps and bands, checked against the first file, and every window must have the same height and width. The second form opens each source with its header, reads them and closes them.

windowsOne window per Dataset, as in read. An entry of nothing reads that whole image, and nothing alone reads every whole image.
time, bandsAs in read.
patternAs in read. nothing uses "n t b y x" or "n b y x", which puts the item axis last in Julia. The item axis stays for one Dataset.

An empty list, a windows list of the wrong length, windows of different sizes, or sources and headers of different lengths throw ArgumentError.

batch = read_many([file, file]; windows = [(1, 1, 2, 3), (3, 4, 2, 3)], bands = [2])
size(batch)                                  # (3, 2, 1, 2, 2)

info

info(file::Dataset) -> Metadata

Returns the metadata Rumi.open read, with these fields.

headerThe canonical external header bytes.
shape(band, y, x), or (time, band, y, x) when the file has more than one time step.
time_countTime steps in the file.
dtypeThe element type name, such as "uint16".
tileThe tile (height, width).
frame_layoutThe axes inside one frame, such as "b h w".
index_orderThe band and time axes outside the frame, outermost first, as the symbols :t and :b. Axes of length one are left out.
framesFrames in the file.
bandsBand descriptions, in band order.
timeDateTime values, or (start, stop) pairs of them.
time_kind:instant or :interval.
transformSix affine coefficients (x_res, row_rotation, x_origin, column_rotation, y_res, y_origin), or nothing without a CRS.
crsThe EPSG code, or nothing.
pixel_is_pointtrue for PixelIsPoint, false for PixelIsArea.
meta = info(file)
meta.shape                                   # (2, 3, 6, 8)
meta.bands                                   # ["B02", "B03", "B04"]

frames

Rumi.frames(x::AbstractArray, pattern; tile_size=512) -> FrameTable

Cuts an array into frames in file order, clipping edge tiles. Compress each frame with Rumi.GeoZL before writing.

xAn array of samples. Its element type is the file's sample type, and it holds the pattern's input axes in reverse, so "b (row h) (col w)" takes (x, y, band), the shape Rumi.read returns. A view works and is copied frame by frame.
patternThe frame pattern Python takes, in C order, such as "b (row h) (col w) -> row col b (h w)".
tile_sizeHeight and width of a square tile, from 1 to 65535.

Returns a FrameTable. A b h w frame is a Julia array shaped (w, h, band).

using Rumi: GeoZL

table = Rumi.frames(image, "b (row h) (col w) -> row col b (h w)"; tile_size = 256)
for (i, tile) in enumerate(table.data)
    table.compressed[i] = GeoZL.compress(tile, GeoZL.graph(tile, "planar>zigzag>pfor"))
end

GeoZL

Rumi.GeoZL.graph(x, method; width=nothing, planes=nothing, error=nothing,
    nodata=nothing) -> Rumi.GeoZL.Graph
Rumi.GeoZL.compress(x, g::Rumi.GeoZL.Graph) -> Vector{UInt8}

Compress frames with the GeoZL linked into librumi. These calls cover graph creation and compression; Rumi.write stores the resulting bytes.

xAn array of a Rumi sample type. missing values take nodata, or NaN in a float array. For a bounded error the graph's x also fixes the domain later tiles must fall in.
methodA recipe such as "planar>zigzag>pfor".
width, planesRow width in samples and the number of stacked images. They default to size(x, 1) and, for three or more dimensions, the last one, which is the planes of a b h w frame.
errornothing or 0 for lossless, a positive number for an absolute bound, a percentage such as "1%" for a relative one, or a full LINEAR, LOG or SQRT recipe.
nodataA sentinel value that marks missing samples. NaN holes in a float array are kept without one.

compress refuses a tile of another element type, and a bounded tile outside the graph's domain. A Graph holds native state, so it is not thread-safe; build one per task.

write

Rumi.write(path, table::FrameTable; bands, time, transform=nothing, crs=nothing,
    pixel_is_point=false) -> Vector{UInt8}

Writes the compressed frames to a local file.

pathA local path. A leading ~ is expanded, and an existing file is replaced.
tableA FrameTable with a non-empty payload in every compressed entry. A missing payload throws ArgumentError naming the first one.
bandsA vector with one unique, non-empty text per band, in band order, such as "B4, Red, 665nm".
timeA vector with one entry per time step. An instant is a Date, a DateTime or an ISO string such as "2025-08-08", and an interval is a (start, end) tuple of them. A Date marks midnight UTC and a DateTime is read as UTC.
transformSix affine coefficients in rasterio order, (x_res, row_rot, x_origin, col_rot, y_res, y_origin). Give it together with crs.
crsAn EPSG code, such as 32631 or "EPSG:32631".
pixel_is_pointtrue when coordinates refer to pixel centres. The default refers to pixel corners.

Returns the external header. Keep it with the path, for example with Base.write. A failed write removes the partial file.

using Dates

header = Rumi.write("scene.rumi", table; bands = ["B02", "B03", "B04", "B08"],
                    time = [Date(2025, 8, 8)],
                    transform = (10, 0, 500000, 0, -10, 8000000), crs = 32618)
Base.write("scene.header", header)

Types

DatasetWhat Rumi.open returns. isopen(file) tells whether it is open and close(file) frees it, which also happens when it is garbage collected. A closed Dataset throws ArgumentError on read.
MetadataWhat info returns, with the fields above.
FrameTableWhat Rumi.frames returns. data holds one array per frame and compressed one payload per frame, nothing until it is set. layout names the axes of one frame, such as "h w", and dtype the sample type. length(table) is the frame count.
RumiErrorA library failure other than an invalid request. Its message comes from librumi.

Arrays

Selections and window origins are one-based. Arrays use Julia's own memory order, so an Image reads as (x, y, band) and a Cube as (x, y, band, time), and read_many adds the item axis last. A Cube read keeps its time axis when one step is selected. Metadata.shape keeps Rumi's (band, y, x) or (time, band, y, x).

A pattern names the output axes from n, t, b, y and x, outermost first. Grouped axes become one dimension, and an axis may be left out only when its extent is one. The Julia array has the dimensions in reverse, so pattern = "t y x b" gives an array shaped (b, x, y, t).

A frame pattern in Rumi.frames reads the same way. "b (row h) (col w)" takes an (x, y, band) array, the order Rasters.jl holds a raster in.

Integer, Float16, Float32, Float64, complex and Bool files read into Julia's own types. bfloat16 reads into Core.BFloat16 where Julia defines it and Rumi.RumiBFloat16 otherwise. The five float8 dtypes read into the 8-bit types Rumi.Float8E4M3FN, Rumi.Float8E5M2, Rumi.Float8E8M0FNU, Rumi.Float8E4M3FNUZ and Rumi.Float8E5M2FNUZ.

What it covers

The Julia binding writes and reads on the CPU. It has no frame_start, GPU read or set_num_threads. Set RUMI_NUM_THREADS before the first parallel read to control the native pool.
