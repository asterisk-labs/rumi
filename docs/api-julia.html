The Julia package reads Rumi Image and Cube files into native Julia arrays. It opens a source with its external header, as the Python and R packages do.

Install

using Pkg
Pkg.Registry.add(url = "https://github.com/asterisk-labs/AsteriskRegistry")
Pkg.add("Rumi")

The package calls librumi directly. It loads the library named by RUMI_LIB, then the one make build writes to core/build in a checkout, then the artifact a release publishes for Linux x86-64 and macOS arm64, downloaded on first use and kept in the Julia depot. Loading fails with a librumi built for another C API version.

using Rumi

file = Rumi.open("scene.rumi", Base.read("scene.header"))
chip = Rumi.read(file; bands = [4, 8], time = 1:3, window = (1, 1, 256, 256))
size(chip)                                   # (256, 256, 2, 3)
meta = info(file)
close(file)

Functions

The module exports Dataset, Metadata, RumiError, info and read_many. open and read are not exported, so call them as Rumi.open and Rumi.read. Bad arguments throw ArgumentError, and a header, source or read that librumi refuses throws RumiError.

open

Rumi.open(source, header) -> Dataset

Pairs a local path or remote URI with its external header. Opening checks that the header matches the source and reads the transform, CRS, band descriptions and time axis. A leading ~ in the path is expanded.

sourceA local path or remote URI.
headerThe external header bytes, any AbstractVector{UInt8}. The Dataset keeps its own copy.

Returns a Dataset. A header that is invalid or does not match the source throws RumiError.

read

Rumi.read(file::Dataset; time=nothing, bands=nothing, window=nothing,
    pattern=nothing) -> Array
Rumi.read(source, header; kwargs...) -> Array

Reads a selection into a new array of the file's element type. The second form opens the source, reads it and closes it.

timeOne-based time steps, an integer or a collection of integers, kept in the order given. nothing reads every step.
bandsOne-based bands, in the same form.
window(row, column, height, width) with a one-based origin. It must lie inside the image, and nothing reads the whole image.
patternThe output axes, as in Arrays. nothing uses "t b y x" when the file has more than one time step, otherwise "b y x".

An empty selection, an index outside the file, a window past the image or a closed Dataset throws ArgumentError.

chip = Rumi.read(file; time = [2, 1], bands = [3, 1], window = (2, 3, 3, 4))
size(chip)                                   # (4, 3, 2, 2)

read_many

read_many(files::AbstractVector{<:Dataset}; windows=nothing, time=nothing,
    bands=nothing, pattern=nothing) -> Array
read_many(sources, headers; kwargs...) -> Array

Reads one window from each Dataset into one array, as a training batch needs. Every file takes the same time steps and bands, checked against the first file, and every window must have the same height and width. The second form opens each source with its header, reads them and closes them.

windowsOne window per Dataset, as in read. An entry of nothing reads that whole image, and nothing alone reads every whole image.
time, bandsAs in read.
patternAs in read. nothing uses "n t b y x" or "n b y x", which puts the item axis last in Julia. With one Dataset the default has no item axis.

An empty list, a windows list of the wrong length, windows of different sizes, or sources and headers of different lengths throw ArgumentError.

batch = read_many([file, file]; windows = [(1, 1, 2, 3), (3, 4, 2, 3)], bands = [2])
size(batch)                                  # (3, 2, 1, 2, 2)

info

info(file::Dataset) -> Metadata

Returns the metadata Rumi.open read, with these fields.

headerThe canonical external header bytes.
shape(band, y, x), or (time, band, y, x) when the file has more than one time step.
time_countTime steps in the file.
dtypeThe element type name, such as "uint16".
tileThe tile (height, width).
frame_layoutThe axes inside one frame, such as "b h w".
index_orderThe band and time axes outside the frame, outermost first, as the symbols :t and :b. Axes of length one are left out.
framesFrames in the file.
bandsBand descriptions, in band order.
timeDateTime values, or (start, stop) pairs of them.
time_kind:instant or :interval.
transformSix affine coefficients (x_res, row_rotation, x_origin, column_rotation, y_res, y_origin), or nothing without a CRS.
crsThe EPSG code, or nothing.
pixel_is_pointtrue for PixelIsPoint, false for PixelIsArea.
meta = info(file)
meta.shape                                   # (2, 3, 6, 8)
meta.bands                                   # ["B02", "B03", "B04"]

Types

DatasetWhat Rumi.open returns. isopen(file) tells whether it is open and close(file) frees it, which also happens when it is garbage collected. A closed Dataset throws ArgumentError on read.
MetadataWhat info returns, with the fields above.
RumiErrorThrown when librumi refuses a header, a source or a read. Its message carries the library's.

Arrays

Selections and window origins are one-based. Arrays use Julia's own memory order, so an Image reads as (x, y, band) and a Cube as (x, y, band, time), and read_many adds the item axis last. A Cube read keeps its time axis when one step is selected. Metadata.shape keeps Rumi's (band, y, x) or (time, band, y, x).

A pattern names the output axes from n, t, b, y and x, outermost first. Grouped axes become one dimension, and an axis may be left out only when its extent is one. The Julia array has the dimensions in reverse, so pattern = "t y x b" gives an array shaped (b, x, y, t).

Integer, Float16, Float32, Float64, complex and Bool files read into Julia's own types. bfloat16 reads into Core.BFloat16 where Julia defines it and Rumi.RumiBFloat16 otherwise. The five float8 dtypes read into the 8-bit types Rumi.Float8E4M3FN, Rumi.Float8E5M2, Rumi.Float8E8M0FNU, Rumi.Float8E4M3FNUZ and Rumi.Float8E5M2FNUZ.

What it covers

The Julia package reads files. It has no frames, write or frame_start, no GPU reads and no set_num_threads, so write files with the Python package. librumi still reads RUMI_NUM_THREADS, an integer from 1 to 1024 or ALL_CPUS, and the first parallel read fixes the pool size.
