The R package reads Rumi Image and Cube files through the native Rumi library. It opens a source with its external header and returns windows, bands and time steps as native R arrays.

Install

install.packages("rumi", repos = "https://asterisk-labs.r-universe.dev")

# or from GitHub
remotes::install_github("asterisk-labs/rumi", subdir = "bindings/r")

A source install builds the bundled Rumi, GeoZL, OpenZL and Karu code with CMake 3.21 or newer. It needs C11 and C++23 compilers, and pkg-config to find libcurl 7.83 or newer and OpenSSL 3.0 or newer. No separate Rumi installation is needed.

library(rumi)

header <- readBin("scene.header", "raw", file.info("scene.header")$size)
file <- rumi_open("scene.rumi", header)
chip <- rumi_read(file, bands = c(4, 8), time = 1:3,
                  window = c(1, 1, 256, 256))
dim(chip)                                    # 256 256 2 3
rumi_close(file)

Functions

Every exported function is below. Bad arguments, a header that does not match its source and a read the library refuses stop with an R error.

rumi_open

rumi_open(path, header)

Opens a source with its external header. Opening checks the header against the source and reads the metadata, and every later read uses this pair.

pathOne local path, URI or VSI path. A leading ~ is expanded.
headerThe external header as a raw vector, as readBin() returns it.

Returns a rumi_dataset with the fields pointer, path, header and metadata. print shows the shape, dtype, tile, frame layout, bands, CRS and first time step. It wraps native state, so it does not survive saving and reloading. Garbage collection closes it, and rumi_close closes it at once.

rumi_info

rumi_info(file)

Returns the metadata read by rumi_open as a rumi_metadata list. It reads nothing from the source.

shapeRumi's canonical (Band, Y, X) for an Image or (Time, Band, Y, X) for a Cube.
time_countNumber of time steps, 1 for an Image.
dtypeThe sample type, such as "uint16".
tileTile height and width.
frame_layoutThe axes of one decoded frame, such as "b h w".
index_orderThe band and time axes the frame index walks, outermost first.
framesNumber of frames.
bandsBand descriptions.
timeUTC POSIXct values. Intervals are a matrix with the columns start and end.
time_kind"instant", "interval" or NULL.
transform, crsThe six affine coefficients and the EPSG code, or NULL when the file has no CRS.
pixel_is_pointTRUE for a PixelIsPoint raster, FALSE for PixelIsArea.
headerThe header bytes.
info <- rumi_info(file)
info$shape                                   # 2 3 6 8
info$bands                                   # "B02" "B03" "B04"

rumi_read

rumi_read(file, header = NULL, bands = NULL, time = NULL,
    window = NULL, pattern = NULL)

Reads a window and a selection of bands and time steps. Only the frames the read needs are fetched.

fileA dataset from rumi_open, or a path. A path is opened with header and closed after the read.
headerThe external header when file is a path. A dataset already carries one, so passing it there is an error.
bandsWhole one-based band indices in output order, or NULL for all.
timeWhole one-based time indices in output order, or NULL for all.
windowc(row, column, height, width) with a one-based origin, or NULL for the whole image. It must lie inside the image.
patternAn output pattern that arranges the result, as in Arrays. NULL keeps the native order.

Returns an array shaped (X, Y, Band) for an Image or (X, Y, Band, Time) for a Cube. A Cube keeps its time dimension when one step is selected.

chip <- rumi_read(file, time = c(2, 1), bands = c(3, 1),
                  window = c(2, 3, 3, 4))
dim(chip)                                    # 4 3 2 2

band <- rumi_read("scene.rumi", header, bands = 1)

rumi_read_many

rumi_read_many(files, windows = NULL, bands = NULL, time = NULL,
    pattern = NULL)

Reads one window from each of several datasets in one call and stacks them along a last sample dimension, as a training batch needs.

filesA list of datasets from rumi_open.
windowsOne c(row, column, height, width) per dataset, as a list or as the rows of a matrix. All windows have the same height and width. NULL reads each whole image.
othersAs in rumi_read, applied to every dataset.

Returns (X, Y, Band, Sample), or (X, Y, Band, Time, Sample) when the first dataset is a Cube. Dimension names come from the first dataset.

batch <- rumi_read_many(list(file, file),
                        windows = list(c(1, 1, 2, 3), c(3, 4, 2, 3)),
                        bands = 2)
dim(batch)                                   # 3 2 1 2 2

rumi_close

rumi_close(file)

Releases the native source and header and returns NULL invisibly. A later read on the dataset stops with an error, and closing it again does nothing.

Arrays

R is column-major, so the axes run in reverse of Python. An Image reads as (X, Y, Band) and a Cube as (X, Y, Band, Time), with the same memory as Python's (Band, Y, X) and (Time, Band, Y, X). Indices and window origins are one-based, and window keeps the (row, column, height, width) order.

The result carries dimnames for bands and time steps, a rumi_axes attribute naming each dimension and a rumi_metadata attribute with the file's metadata. Time names are UTC timestamps, and an interval is written as start/end.

A pattern uses the axes n, t, b, y and x as in Python, and R gets them in reverse. "b x y" gives a (Y, X, Band) array, the order of terra::as.array(). An axis left out must have length one after selection. A result read with a pattern has no dimnames and no Rumi attributes.

Sample types

bool reads as logical, and uint8, int8, uint16 and int16 as integer. complex32, complex64 and complex128 read as complex. The other integer and float types read as double, and float64 decodes straight into the R array. 64-bit integers above 253 lose precision and raise a warning.

R has no 8-bit float, so the five float8 types return their native bytes as a raw array of class rumi_float8_array.

What it covers

The R package has the open, info, read and read_many calls of the Python package. It does not write files, so cut and write them in Python and read them here with their headers. It has no GPU reads and no thread or checksum setters.

Reads use one decode thread and skip OpenZL checksums unless RUMI_NUM_THREADS or RUMI_VERIFY=1 is set before the first read. RUMI_NUM_THREADS takes a count or ALL_CPUS, and Sys.setenv() sets it from R.
